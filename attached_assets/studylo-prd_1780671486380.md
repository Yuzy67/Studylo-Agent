## 1. PRODUCT OVERVIEW

### 1.1 Product Name
**Studylo** — *Your AI-Powered Study & Build Companion*

### 1.2 Tagline
> *"Search smarter. Learn deeper. Build faster."*

### 1.3 Vision Statement
Studylo is an AI-first research and productivity platform built for high school students, university learners, and vibe coders. It merges the intelligence of an AI research assistant with a full-stack developer co-pilot — giving every user the tools to study, build, and ship, all in one place.

### 1.4 Mission
To democratize access to intelligent study support and developer tooling — making complex academic topics approachable and making project development faster, cleaner, and deployable with confidence.

## 4. DESIGN SYSTEM

### 4.1 Design Philosophy
> *"Humanized Minimalism with Dark Energy"*

The UI must feel like it was hand-crafted by a passionate designer — not generated. It must communicate trust, intelligence, and warmth simultaneously. Think of a luxury dark-mode app built for students who take aesthetics seriously.

### 4.2 Visual Language

#### Glassmorphism
- Frosted glass cards with `backdrop-filter: blur(20px)`
- Semi-transparent backgrounds: `rgba(255,255,255,0.05)` to `rgba(255,255,255,0.1)`
- Subtle inner borders: `1px solid rgba(255,255,255,0.1)`
- Used on: Chat containers, result cards, modals

#### Claymorphism
- Soft, rounded 3D-like UI elements
- `border-radius: 20px–32px` with layered shadows
- `box-shadow: 0 8px 32px rgba(139, 92, 246, 0.2), inset 0 1px 0 rgba(255,255,255,0.1)`
- Used on: Feature mode buttons, active states, CTA cards

#### Interactive Elements
- Buttons have magnetic hover effect (translate on hover)
- Micro-animations on every click (scale + ripple)
- AI response streaming with blinking cursor
- Smooth route transitions (slide + fade)
- Skeleton loaders that glow purple while fetching

### 5.4 OpenAI Integration Strategy

**Model:** `gpt-4o` for all complex tasks  
**Model:** `gpt-4o-mini` for flashcard generation and quick summaries (cost optimization)

**API Route Pattern (Streaming):**
```typescript
// app/api/chat/route.ts
import OpenAI from "openai";

const openai = new OpenAI({ apiKey: process.env.OPENAI_API_KEY });

export async function POST(req: Request) {
  const { messages, mode, systemContext } = await req.json();
  
  const stream = await openai.chat.completions.create({
    model: "gpt-4o",
    stream: true,
    messages: [
      { role: "system", content: SYSTEM_PROMPTS[mode] },
      ...messages,
    ],
  });
  
  return new Response(stream.toReadableStream());
}
```

**System Prompt Modes:**
- `study` — Academic tutor persona, curriculum-aware
- `research` — Research analyst, cites reasoning steps
- `devtools` — Senior full-stack engineer + product manager
- `vibe-coder` — Startup co-founder + tech architect
- `notes` — Summarization + flashcard specialist

## 7. USER FLOWS

### Flow 1 — Student Asking a Study Question
```
Land on Home → Type question in search bar → Select "Study" mode 
→ Hit Enter → Chat page opens → Streaming response renders 
→ User clicks "Explain differently" → Follow-up response streams
→ User copies answer or saves chat
```

### Flow 2 — Vibe Coder Generating a PRD
```
Land on Home → Select "Vibe Coder" chip → Click "Dev Tools" 
→ Type project idea → Select output: "All" → Click Generate 
→ Tabbed output appears (PRD, TRD, Sitemap, Prompt, Code) 
→ User copies PRD or downloads as Markdown
→ Vercel Deploy Guide renders at bottom
```

### Flow 3 — Developer Getting Starter Code
```
Enter Dev Tools → Describe project → Select "Starter Code" + "Next.js" 
→ Generate → Code renders with syntax highlighting 
→ Copy to clipboard → Deploy instructions shown
```
